运行时配置

llama-server 路径
本地 llama.cpp 服务器可执行文件所在目录
监听地址 (host)
服务绑定地址。0.0.0.0 会暴露在局域网
端口 (port)
本地服务监听端口。默认 8080
上下文长度 (ctx_size)
模型能记住的对话长度。设太高会 OOM
⚠️ 默认 32768，超过 65536 可能显著增加内存占用
最大输出 (n_predict)
单次生成最大 token 数。-1=按模型默认
请求超时 (request_timeout_ms)
长回答和低速模型不应轻易超时

模型配置

模型文件
GGUF 格式模型文件路径
视觉模型 (mmproj)
用于图片理解。没有时上传只能预览
模板参数 (chat_template_kwargs)
控制模板行为，如 Qwen 思考模式

采样参数

Temperature
控制输出随机性。0.7=平衡，0=确定，1=创意
Top-K
只考虑概率最高的 K 个词
Top-P
只累积概率达到 P 的词
重复惩罚 (repeat_penalty)
<1 鼓励不重复。循环回答时调低

GPU 配置

GPU 层数 (gpu_layers)
-1=全部，0=不进显存，1-100=具体层数
线程数 (threads)
CPU 并行线程数。R9 7845HX (20核) 建议 16
类型 K (type_k)
KV 缓存 K 通道精度。f16 省一半显存

高级选项

Flash Attention
加速注意力计算，节省显存。CUDA 13.3 支持
MMap 加载
内存映射加载模型。开启加速，关闭防崩溃
额外参数 (extra_args)
高级用户补充参数，用空格分隔

日志设置

日志级别
终端日志显示级别
过滤流式 JSON
隐藏流式输出中的 JSON 噪音
保留最近日志条数
终端日志保留条数。过多会占内存

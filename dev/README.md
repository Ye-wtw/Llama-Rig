# dev/ —— 开发用素材，**不参与打包**

`files:` 白名单是 `assets/** desktop/** renderer/** package.json`，
本目录不在其中，因此里面的东西不会随安装包发给用户。

## presets/

开发期自用的一批预设（Bonsai / Qwen 系列）。它们原本放在 `desktop/configs/`，
而 `desktop/**` 在打包清单里 —— 结果是**每个新用户装完都会得到这批预设**。

现在移到这里：
- 发布版首次运行**不带任何预设**，用户从零开始（干净的起点）
- 开发时想用这批预设，把文件拷进运行期预设目录即可：
  - 开发实例的运行期目录是项目根的 `configs/`（未打包时 `appOwnDir` = 项目根）
  - 打包版是 exe 同级的 `configs/`

## 开发机便利路径

源码里**不再内置任何开发机目录名**（公开仓库不该出现作者本机的路径命名）。
需要时用两个环境变量直接指向目标目录：

| 环境变量 | 用途 |
|---|---|
| `LLAMA_RIG_DEV_MODELS_DIR` | 模型根目录（顶栏「模型」菜单扫描 gguf 的范围） |
| `LLAMA_RIG_DEV_LEGACY_DIR` | 旧版安装目录（首次运行播种 `config.toml` 与预设的来源） |

不设这两个变量时默认值一律为空，一切交给首次运行向导让用户自己选目录 ——
这正是发布版面对其他用户时的正确行为。
